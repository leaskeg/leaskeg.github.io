01About

From idea to the store listing.

I'm a full-stack developer from Denmark with an AP degree in Computer Science from UCL University College, Odense (2024). I like taking an idea all the way: design, code, tests, release and the store listing.

Recently that has meant two Android apps published on Google Play, a competitive browser game with a global leaderboard, a WordPress theme for a Swedish property company, and a set of Discord bots and tools used daily by gaming communities.

I care about clean architecture, automated tests and the small details, like audio loops that are sample-exact.

Upload a screenshot of a base, get the video that shows how to beat it.

Discord bot · Computer vision
Project details

An indexing pipeline discovers new videos from curated YouTube channels, extracts and quality-filters frames, normalizes the base region, and stores ORB keypoint descriptors. It replaced an earlier perceptual-hash matcher after measuring collisions: ORB separated same-base pairs (~144 good matches) from different bases (~3). Exposed through a Discord bot.

  • Measured, then replaced perceptual hashing with ORB keypoints
  • ~144 good matches for the same base vs ~3 for different bases
  • Automatic discovery and frame quality-filtering of new videos
