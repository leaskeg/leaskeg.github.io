PC tips

Skip the PC cleaners.

Don't install "PC cleaner" or "registry cleaner" apps. Windows already has safe, built-in commands that do the same job, for free and without ads or upsells.

How to run these: right-click the Start button, choose Terminal (Admin) or Windows PowerShell (Admin), then paste a command and press Enter.

TL;DRThe one-line checkup

Repairs Windows, checks the disk and optimizes the drive. Restart the PC when it's done.

DISM /Online /Cleanup-Image /RestoreHealth; sfc /scannow; chkdsk C: /scan; Optimize-Volume -DriveLetter C

01Update all your programs

Updates every program winget knows about, silently.

winget upgrade --all --silent --accept-package-agreements --accept-source-agreements --include-unknown --disable-interactivity

Close games and launchers first. If one program blocks the run, skip it with winget pin add --id <Id> and run the command again.

02Fix corrupted Windows files

DISM repairs Windows' own backup copy, then SFC uses it to fix broken system files.

DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow

DISM can look stuck at 62%. That's normal, so let it finish.

03Check the disk for errors

Scans the drive while you keep using the PC.

chkdsk C: /scan

If it finds problems, run chkdsk C: /f and press Y to repair at the next restart.

04Free up space

Clears temp files and old Windows Update leftovers.

cleanmgr /sagerun:1
DISM /Online /Cleanup-Image /StartComponentCleanup
Remove-Item "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue

First time? Run cleanmgr /sageset:1 once and tick what you want cleaned.

05Optimize the drive

Windows picks the right fix itself: TRIM for an SSD, defragmenting for a hard disk.

Optimize-Volume -DriveLetter C -Verbose

06Scan for malware

Updates Microsoft Defender and runs a full scan. No extra antivirus needed.

Update-MpSignature; Start-MpScan -ScanType FullScan

A full scan can take an hour or more.

07Find what's slowing it down

Lists programs that start with Windows, and the ones using the most CPU.

Get-CimInstance Win32_StartupCommand | Select Name, Command
Get-Process | Sort CPU -Descending | Select -First 15 Name, CPU, WS

Turn startup apps off in Task Manager → Startup apps. Game launchers are the usual suspects.

08Fix internet problems

Resets the DNS cache and the network stack.

ipconfig /flushdns
netsh winsock reset
netsh int ip reset

Restart the PC afterwards.
